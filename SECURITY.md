# Security Policy

## Project Status

HyperQwen Hardened is an unofficial, experimental, community-maintained security-hardening project based on HyperQwen.

This project is not affiliated with or endorsed by the original HyperQwen maintainers.

## Supported Versions

Security fixes are prioritized for the latest published release. Older versions may not receive updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository, please report it privately through GitHub's **Report a vulnerability** feature, if available.

Please avoid publicly disclosing exploitable security vulnerabilities before the maintainer has had an opportunity to investigate.

If private vulnerability reporting is unavailable, open a public issue requesting a private reporting method without including exploit details or sensitive information.

## Scope

Reports concerning the hardening Dockerfiles, modified scripts, dependency management, or security configuration are welcome.

Vulnerabilities originating in upstream HyperQwen or third-party dependencies may need to be reported to their respective maintainers.

## Security Limitations

This project does not claim to eliminate all vulnerabilities.

Known limitations and remaining vulnerability scan findings are documented in the README.

Security reports will be reviewed as maintainer availability permits. No fixed response or remediation timeline is guaranteed.
